# Unified Nav

For this ScholarDesk Admin site, I feel like the navigation bar background color(white/light) seems separated from the Hero section which hurts UI/UX.

I think, the navigation bar should be designed/styled so that it has a similar background with the Hero section and change when scroll starts so that it doesn't appear separate from the rest of the site.

For pages that do not have Dark background Hero Sections, we may need to maintain the light/white background or whatever design you feel fit for our users.

For the Mobile view, we need to use the Wordmark signature instead of the full wordmark at the top and the footer.
